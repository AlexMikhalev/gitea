## Research Findings (Day 1)

### Gitea Markup Architecture
- Pluggable renderer system in `modules/markup/`
- `Renderer` interface: `Name()`, `FileNamePatterns()`, `SanitizerRules()`, `Render()`
- Built-in renderers: markdown, orgmode, csv, console, asciicast, openapi
- External renderers via `[markup.*]` config sections
- Registration via `init()` functions and `markup.RegisterRenderer()`

### Quarto Overview
- Scientific publishing system built on Pandoc
- `.qmd` file extension for Quarto Markdown
- CLI: `quarto render <file.qmd> --to html`
- Features: code execution, equations, cross-refs, citations, callouts

## Decisions Made
- Will use external renderer approach (simpler, leverages existing infrastructure)
- Quarto will render to standalone HTML
